# Document extraction fixtures

`sample.doc`, `sample.ppt`, `sample.pptx`, `sample.xls`, and `sample.rtf` are test fixtures from
Firecrawl AnyDoc tag `v0.1.9` (commit `e754e1d33a1a540ebc9226e36f11d3f401852c9e`), matching the
exact dependency version used by this package. They are redistributed under AnyDoc's MIT license.

The remaining fixtures are small documents generated specifically for this repository's parser tests.
