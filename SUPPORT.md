# Support

opencompany is maintainer-led software under active development. Community support is best-effort
and focuses on the documented development setup. The repository does not currently promise
production-grade self-hosting support, backwards compatibility for unreleased interfaces, or a
response-time SLA.

Before asking for help:

1. Read the root README and the documentation under `docs/`.
2. Search existing issues.
3. Reproduce the problem on the latest `main` branch with credentials and private data removed.

Use the bug report form for reproducible defects and the proposal form for scoped improvements.
Maintainers may close requests that cannot be reproduced, fall outside the supported development
surface, or require product/account-specific support.

Never post secrets, customer information, or vulnerability details in an issue. Follow
[SECURITY.md](./SECURITY.md) for suspected vulnerabilities and
[CODE_OF_CONDUCT.md](./CODE_OF_CONDUCT.md) for conduct concerns.
