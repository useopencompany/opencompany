## What the connection does

Stripe is a workspace-owned, read-only tool connector for main chat. Once connected, Goat can answer bounded questions about:

- Payment and balance activity for a period, including captured payment volume, refunds, disputes, net Stripe fees, and net payment activity by currency.
- Current available and pending Stripe balances.
- Subscription health, cancellations scheduled at period end, and estimated monthly recurring value by currency.
- Open receivables, overdue invoices, failed collection attempts, and the largest outstanding invoices.

The payment-activity summary is operational Stripe reporting, not GAAP revenue. Revenue recognition, taxes, activity outside Stripe, and accounting policy can produce different figures. Estimated MRR includes fixed recurring price amounts and reports trialing and at-risk value separately; metered, tiered, transformed-quantity, and unpriced items are excluded.

Stripe is intentionally excluded from automatic Brain-fill surveys because these metrics are live operational state. Chat does not save Stripe results to Brain unless the user explicitly asks.

## Connect Stripe

Only a workspace admin can connect or disconnect Stripe.

1. In Goat, open **Settings → Integrations → Stripe** and choose **Connect Stripe**.
2. Stripe opens its app authorization screen. Sign in, select the Stripe account for this workspace, and review the requested permissions.
3. Approve the read-only account, balance, subscription, invoice, and app-lifecycle event permissions. The lifecycle permission lets Goat remove stored access when the app is uninstalled. You must be an administrator of the Stripe account.
4. Stripe returns you to Goat with the connected account.

Goat validates each required read endpoint before completing the connection. Stripe OAuth access and refresh tokens are encrypted with the integration credential key, remain server-side, and are never sent to the model or browser. Access tokens refresh automatically, and Stripe rotates the refresh token on every exchange. Goat never requests a write permission and cannot create charges, refunds, subscriptions, or invoices.

Disconnecting in Goat deletes its stored authorization. Uninstalling Goat under **Stripe → Settings → Installed apps** also disconnects the matching Goat workspace automatically.

## Use it in chat

Examples:

- “How much payment volume did we process last week, net of refunds and Stripe fees?”
- “What is available in Stripe right now?”
- “Give me subscription health and estimated MRR.”
- “How much is outstanding, and which open invoices need attention?”

Main chat first discovers the Stripe action contract, then runs the relevant read. Large periods are paginated and bounded; a partial result tells the model to narrow the date range.
