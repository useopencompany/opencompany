## What integrations do

Integrations connect external systems to Goat so chat, tasks, and Brain ingestion can work from live company context. Some integrations expose tools to agents; others feed source items into the Brain ingestion queue.

## Current categories

- **Tool connectors** let Goat call a provider API on the user's behalf. Gmail, Google Calendar, Google Drive, GitHub, Linear MCP, Slack, and Stripe use OAuth; Attio uses a workspace API key. Main chat exposes curated actions across these connections. Linear can create or update issues and add comments, Calendar can create events, and Attio can update records or existing list entries. These writes require confirmation by default. Stripe requests only read permissions and its actions are read-only.
- **Brain source connectors** turn external activity into `goat.brain_source_items` and enqueue durable Brain ingestion. Jamie meeting notes, Granola meeting notes, Slack conversations, Linear issue activity, and chat captures use this shape.
- **Webhook connectors** receive provider deliveries at Goat API routes. Incoming payloads must authenticate at the route boundary before they can enqueue work.
- **API-key poll connectors** store a provider API key and let Goat poll for new activity when the provider offers no webhooks. Granola uses this shape.

## Where to configure

Personal OAuth integrations and workspace connections live under **Settings → Integrations**. Brain source routing lives on each brain's settings page under Sources. Stripe is workspace-owned and can only be authorized or disconnected by a workspace admin.
