---
title: Self-hosting
description: Current status of opencompany self-hosting documentation.
---

Complete self-hosting instructions are coming soon. The repository currently contains separate web,
API, runner, and database-backed runtime surfaces, but it does not yet publish a supported
single-command installation, production sizing guide, upgrade policy, or compatibility promise for
self-hosted operators.

Until that contract is defined, do not treat the contributor development setup as a production
deployment guide. The opencompany open-source planning work owns the deeper installation, security,
operations, and upgrade documentation that will replace this placeholder.
