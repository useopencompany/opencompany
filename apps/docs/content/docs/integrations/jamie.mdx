## What connecting does

Jamie is a workspace-managed meeting source. Setup creates the OpenCompany webhook destination and
associates Jamie's API-key-authenticated deliveries with the workspace.

## Scopes and permissions

Jamie uses a provider API key and signed delivery path rather than a general agent-action catalog.
A field-by-field setup and delivery troubleshooting guide is coming soon.

## Brain ingestion

Jamie has no channel or document picker. After the connection is enabled for a Brain, each completed
meeting delivery can create a durable ingestion job for its notes and transcript material.
