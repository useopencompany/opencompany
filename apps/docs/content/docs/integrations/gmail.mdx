Use the Gmail Plugin to search mail, read threads, download attachments, create drafts, send email,
and organize your mailbox.

Sending is deliberately the sharpest tool here: `send_email` delivers immediately and can't be
recalled, so it sits in the **Send & organize Gmail** group and asks before every send by default.
When you want a review step, ask for a draft instead.

## Connect Gmail

1. Ask a workspace admin to install **Plugins → Gmail**.
2. Open the Plugin page and connect your own Google account.
3. Complete Google's consent flow, then check the connected account in opencompany.
4. Review the three permission groups.

Accounts connected before the Plugin shipped may need to reconnect to grant the full tool set.

## Try it

```text
Find the thread about the September release from the last seven days.
Summarize the open questions and create a reply draft for me to review in Gmail.
```

In interactive Chat, approve the proposed reads and draft creation when prompted. Open Gmail to
review and send the draft.

To send instead of drafting, say so explicitly:

```text
Reply to Ada's last message in that thread and send it: tell her the release ships Thursday.
```

Replies sent this way stay in the original thread. Review the recipients and body in the approval
prompt before you approve, because the send can't be undone.

## Permissions

| Group | What it allows | Default |
| --- | --- | --- |
| **Read Gmail** | Search and read messages, threads, drafts, and labels; download attachments | Ask |
| **Create drafts** | Create a draft in Gmail | Ask |
| **Send & organize Gmail** | Send email; add or remove labels, create labels, and move mail to or from trash | Ask |

Coding sessions receive only tools set to **On**. Newly discovered or unclassified tools require
confirmation. See [Permissions](/docs/core-concepts/integrations) before using Gmail in a Workflow.

Sending and mailbox organization share one permission group, so there is no way to allow automatic
labeling while still being asked before each send. Leave **Send & organize Gmail** on **Ask** (the
default) unless you want the agent to send email without confirming.

Google's `gmail.modify` scope covers a broader set of operations than the Plugin exposes. Granting
that scope doesn't add permanent deletion or spam tools to opencompany.

## Attachments and limits

Attachment downloads are limited to 20 MB and use links that expire after five minutes. If a link
expires, ask the agent to download the attachment again. A coding session can work with the original
file, or the agent can publish it as a file for you.

The connected account determines which mailbox is accessible. Confirm the account and target
messages before approving mailbox changes.

## Feed Wiki separately

Open **Wiki → Sources → Gmail** to select supported sent or received email events and add ingestion
instructions. The resulting Wiki knowledge is shared with your workspace, so scope it accordingly.

Connecting Gmail alone doesn't ingest the mailbox. Existing built-in Gmail actions can remain as a
fallback until the Plugin is installed; installation replaces that tool surface without turning on
Wiki ingestion.
