## What the Plugin does

Fathom is an official Agent Plugin backed by [Fathom's hosted MCP server](https://developers.fathom.ai/mcp-docs).
It lets opencompany search meetings, find people, list teams, resolve recording IDs, and read meeting
summaries, action items, and transcripts.

The Plugin is installed once for a workspace. Each person connects their own Fathom account, and
Fathom limits results to meetings that account can access.

## Connect Fathom

1. Ask a workspace admin to install Fathom under **Settings → Plugins → Fathom**.
2. On the Fathom Plugin page, choose **Connect Fathom account**.
3. Sign in to Fathom and approve access.
4. Return to the Plugin page and confirm tool discovery is ready.

OAuth credentials remain encrypted and server-side. The Plugin gateway sends them only to the
reviewed `https://api.fathom.ai/mcp` endpoint.

## Permissions and limitations

All reviewed tools are grouped under **Read Fathom meetings** and default to **Ask** because meeting
content, participant details, team names, and account identity can be sensitive. Turn the group
**On** only when automatic access is appropriate for that account. Newly discovered tools remain
**Ask** until opencompany reviews and classifies them.

Fathom search covers meeting titles and summaries rather than the full transcript. Retrieve a
meeting transcript after resolving its recording ID when you need details that did not reach the
summary. Availability and result scope still follow the connected account's Fathom plan and sharing
permissions.

## Legacy Brain ingestion

Existing API-key connections continue to poll completed meetings into Wiki/Brain as a fallback.
Installing the Plugin does not reuse or replace that API key: MCP OAuth tokens are audience-bound
and cannot power ingestion. Configure the legacy source from **Wiki → Sources** only if you need
automatic meeting ingestion; the old Fathom card is no longer shown in general Integration settings.

Live polling does not automatically import meetings from before the API-key connection. Use
**Import company context** to seed recent history. If a completed meeting is missing, confirm the
legacy source is enabled and allow time for Fathom to finish its summary and transcript.
