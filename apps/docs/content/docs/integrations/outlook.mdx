---
title: Outlook
description: Read and organize Outlook mail and save drafts for review.
---

Install **Outlook** from **Settings → Plugins**, then choose **Connect account**.
Sign in with your work, school, or personal Microsoft account and approve the requested access.
Some organizations require an administrator to approve connections.

Outlook can search and read messages and conversations, download file attachments up to 20 MB,
create drafts, and organize messages using folders and categories. All permissions start in **Ask**,
so you can review an action before it runs.

Drafts stay in Outlook for you to review and send. The plugin cannot send mail or permanently
delete messages. Trash moves mail into Deleted Items. Attachment download links expire after
five minutes; request a new link if needed. Embedded Outlook items and reference attachments
cannot be downloaded.

Your most recently connected Microsoft account powers mail tools. Outlook Calendar has its own
connection and permissions. Outlook is a tools integration and does not import mail into Wiki.
Disconnect the account in plugin settings to remove opencompany's access.
