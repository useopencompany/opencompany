---
title: Outlook Calendar
description: Read your Microsoft calendar, check availability, and manage meetings.
---

Install **Outlook Calendar** from **Settings → Plugins**, then choose **Connect account**.
Sign in with your work, school, or personal Microsoft account and approve calendar access.
Some organizations require administrator approval. Every permission starts in **Ask**.

Read events, check your calendar's busy times, create timed events, update or delete individual
meetings, and respond to invitations. Adding attendees sends invitations; changes can send updates,
and deleting a meeting you organize sends cancellations.

Your own availability works with both Microsoft 365 and personal Outlook accounts. Checking
colleagues or rooms requires Microsoft 365. Availability is checked for the selected calendar;
check other calendars too if you use more than one. Query windows can cover up to 31 days.

For recurring meetings, select a specific occurrence. Creating recurring or all-day events and
changing an entire recurring series are not supported in this version. Use Outlook for those tasks.

Your most recently connected Microsoft account powers calendar tools. The mail plugin has separate
permissions. Disconnect the account in plugin settings to remove opencompany's access.
