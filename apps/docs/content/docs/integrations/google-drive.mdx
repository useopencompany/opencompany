## What connecting does

Google Drive is a personal OAuth connection. Current actions can discover files, read supported
Google Docs and Sheets, create Docs, make exact Doc text replacements, and update or append Sheet
values when permitted.

## Scopes and permissions

File reads and document or spreadsheet edits have separate action modes. Accounts connected before
write support was added may need to grant added Google permissions. A complete scope and file-type
matrix is coming soon.

## Brain ingestion

Select individual files, recursive folders, or supported Shared Drive locations in the destination
Brain. opencompany tracks later changes within that selection. Drive remains the canonical home;
Brain stores sourced knowledge rather than a silent full mirror.
