title: Google Drive
description: Find files, read documents, and create or edit Google Docs.
---

Use the Google Drive Plugin to search files, read or download content, inspect permissions, create
or copy files, and edit existing Google Docs.

## Connect Google Drive

1. Open **Settings → Plugins → Google Drive**.
2. Ask a workspace admin to install it if needed.
3. Select **Connect Google Drive account** and complete Google's consent flow.
4. Review the permission groups before using a tool.

Each person connects their own account. The most recently connected Drive account powers the
Plugin's tools. Google and Shared Drive permissions determine which files it can access.

If your account was connected before Google Docs editing was added, reconnect it to grant the
required `drive.readonly`, `drive.file`, and `documents` scopes.

## Try it

```text
Find the release checklist in Google Drive and read it.
Compare it with the test results in this conversation.
Propose the exact updates to the checklist, then ask me before editing the Google Doc.
```

Use a document URL or file ID when several files have similar names.

## Permissions

| Group | What it allows | Default |
| --- | --- | --- |
| **Browse Drive files** | Search files, list recent files, and inspect metadata | Ask |
| **Read files & permissions** | Read or download content and inspect permissions | Ask |
| **Create & edit files** | Create or copy files and edit Google Docs | Ask |

Interactive Chat pauses for approval. Coding sessions receive capabilities set to **On**, and the
Google Docs edit operations have an additional explicit approval requirement. Newly discovered
unclassified tools require confirmation.

## Edit Google Docs

For a focused change, ask for an exact text replacement, optionally within one tab. For a full
rewrite, specify the target tab and review the proposed content first.

Full-content replacement removes that tab's existing body formatting and embedded content before
rebuilding it. Markdown can create native headings, lists, checkboxes, inline emphasis, links, and
code formatting. Both focused edits and full replacements require explicit approval.

## File limits

Downloads and uploads are limited to 5 MB. Supported document reads accept files up to 20 MB and
return at most 200 KB of extracted Markdown. Scanned, image-only, encrypted, or unsupported files
cannot be read through this path.

The Plugin doesn't expose tools for deleting, moving, or sharing files.

## Save knowledge in Wiki

Drive isn't offered by the current **Wiki → Sources** picker. To reuse a document's findings, ask
the agent to read it and save a reviewed summary with its source link in Wiki. Legacy Brain source
configuration, where enabled, is separate from the current Wiki UI.
