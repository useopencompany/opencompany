Open **Plugins** in the sidebar to browse available packages. A workspace admin installs the Plugin;
then connect the account it should use and review its permission groups.

Start with [Connect your tools](/docs/getting-started/connecting-sources) if this is your first
connection. Use the guides below for provider-specific setup and limitations.

## Coding engines and browser access

Connect [Codex](/docs/integrations/codex) or [Claude Code](/docs/integrations/claude-code) under
**Settings → Inference**. These authorize coding engines and have separate setup from tool Plugins.

[Browser profiles](/docs/integrations/browser-profiles), when enabled for your account, live under
**Settings → Account**.

## Knowledge sources

Live tools and continuous knowledge ingestion are configured separately. The current **Wiki →
Sources** picker offers Gmail, Linear, and Granola. Read [Wiki](/docs/core-concepts/wiki) before
enabling a source; installing a Plugin doesn't automatically copy provider content into Wiki.
