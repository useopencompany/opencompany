title: Integrations
description: Provider connections represented in the current OpenCompany settings UI.
---

Open **Settings → Integrations** to manage connections. The UI separates shared workspace tooling
from personal accounts that act as the signed-in person. Some personal provider accounts are shown
in the Workspace group because they provide shared CRM, meeting, or issue-tracking context.

The pages in this section match the providers and connection surfaces in the current product UI.
They record the behavior verified in the app today. Detailed provider scope matrices and complete
ingestion examples are still being written; each provider page calls out that gap directly.

Connecting an account and feeding Brain are separate operations. See
[Connecting sources](/docs/getting-started/connecting-sources) before enabling ingestion.

Feature-gated iMessage and Browser profiles pages are included so the documentation matches the UI
when those preferences are enabled. Experimental connectors that are not represented in the current
settings UI are not listed as generally available integrations.
