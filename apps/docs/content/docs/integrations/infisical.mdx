## What connecting does

Infisical is a workspace connection managed by workspace admins. The browser-token handoff makes the
real Infisical CLI available to authorized cloud coding work without placing the token in Chat.

## Scopes and permissions

The connected Infisical account and host determine what the CLI can reach. A detailed explanation of
token lifetime, provider-side roles, and coding-sandbox handoff is coming soon. Until then, grant the
narrowest Infisical access needed for the repositories and environments involved.

## Brain ingestion

Infisical is not a Brain source. Connecting it does not copy secrets or project values into Brain.
