---
title: Linear
description: Work with issues, trigger Workflows, and separately select activity for Wiki.
---

Use the Linear Plugin to read issues, projects, teams, and comments, or to create and update issues
when permitted. Wiki ingestion and Workflow event settings are separate from tool permissions.

## Connect the Plugin

1. Open **Settings → Plugins → Linear** and have a workspace admin install it.
2. Connect the Linear account you want the agent to use.
3. Review the **Read Linear** and **Manage issues** permission groups.
4. Test a request against a specific team or issue.

```text
Read ENG-123 and its comments in Linear.
Summarize the reported behavior, missing reproduction details, and next action.
```

Replace `ENG-123` with an accessible issue. The installed Plugin defaults reads to **On** and
issue management to **Ask**. Check the current settings before using it in unattended work.

## Trigger a Workflow

On the Linear Plugin page, enable a supported event for the workspace. Then open a Workflow, choose
**On an event**, and select the event, connected account, and team.

The current Plugin supports **Issue created**. Event options depend on the installed Plugin version
and which events are enabled. Existing **issue enters triage** triggers require a team with Triage
enabled. Follow [Workflows and schedules](/docs/core-concepts/workflows-and-schedules) to test a run.

## Feed Wiki

Open **Wiki → Sources → Linear** and connect the separate ingestion account. Select the teams and
issue or comment event types that should contribute knowledge, then enable the source.

The MCP tool connection isn't used as a Wiki ingestion connection. Connecting the Plugin or
enabling a Workflow event alone doesn't feed issue activity into Wiki.

If an event or source stops working, check the account status, selected team, and enabled settings.
