## What connecting does

X is a personal OAuth connection. You can add more than one account and ask Chat to publish for a
specific connected identity.

## Scopes and permissions

Posting defaults to **Ask**. opencompany rejects identical or substantially similar cross-account
copy. The exact X OAuth scope and publishing-policy reference is coming soon. The connected posting
account is separate from opencompany's managed, read-only public X research tools.

## Brain ingestion

Connected X accounts are not configurable Brain sources in the current UI.
