## What connecting does

Latitude is a personal OAuth connection for observing, understanding, and improving AI agents. Its
available tools are discovered from Latitude's live MCP server rather than copied into a fixed local
catalog.

## Scopes and permissions

Tools Latitude marks read-only default to **On**; mutations and tools without a read-only annotation
default to **Ask**. The provider's current OAuth scopes and MCP annotations are authoritative. A
detailed tool reference is coming soon.

## Brain ingestion

Latitude is not a configurable Brain source. Save a result explicitly if it should become durable
workspace knowledge.
