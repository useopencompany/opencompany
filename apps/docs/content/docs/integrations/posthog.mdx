## What connecting does

PostHog exposes a reviewed analytics tool catalog. opencompany can inspect dashboards and saved
insights, run focused analytics queries, and create an insight on a selected dashboard when allowed.

## Scopes and permissions

Analytics reads and insight creation have separate action modes; creating an insight defaults to a
confirmation boundary in the current UI. Detailed OAuth scopes and result-size limits are coming
soon. Analytics may contain sensitive customer data even when no mutation is performed.

## Brain ingestion

PostHog is not a configurable Brain source. Results only enter Brain when a user explicitly captures
material through a supported save path.
