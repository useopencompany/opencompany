title: Attio
description: Search and update CRM data through your connected Attio account.
---

The Attio Plugin uses Attio's hosted MCP server to work with CRM data. It acts as the Attio user
you authorize and respects that account's access.

## Connect Attio

1. Open **Settings → Plugins → Attio** and have a workspace admin install it.
2. Select **Connect Attio** and sign in.
3. Choose the Attio workspace you want opencompany to use and approve access.
4. Review the permission groups after returning.

## Try it

```text
Find the company record for Acme in Attio.
Summarize its current details and recent notes, with links to the records used.
List any information that looks incomplete.
```

Replace the company name with a record in your CRM. If the wrong workspace appears, reconnect and
choose the intended Attio workspace.

## Permissions

| Group | What it allows | Default |
| --- | --- | --- |
| **Inspect Attio structure** | Schemas, attributes, list definitions, teams, and connected identity | On |
| **Read CRM data** | Records, emails, notes, transcripts, tasks, comments, reports, and supported queries | Ask |
| **Change Attio** | Create, update, merge, or delete operations | Ask |

Newly added unclassified tools require confirmation. The read-only SQL query tool isn't available
on every Attio plan. Provider rate limits can also affect large jobs.

## Knowledge ingestion

The current **Wiki → Sources** picker doesn't offer Attio. If you have a legacy Attio ingestion
connection, its access token and webhook are separate from the Plugin's OAuth connection.
Connecting or reconnecting the Plugin doesn't configure that legacy source.

To keep a CRM finding in the current Wiki, ask the agent to save a reviewed summary and link to
the original Attio record.

See [Attio's MCP documentation](https://docs.attio.com/mcp/overview) for provider-specific behavior.
