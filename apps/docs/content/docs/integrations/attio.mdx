## What connecting does

Attio uses a workspace API key. Current agent actions can search and update records, work with lists
and list entries, and add comments when those actions are permitted.

## Scopes and permissions

The Attio key defines the provider-side boundary. opencompany also applies action modes and a
reviewed catalog. A complete key-permission and action table is coming soon.

## Brain ingestion

Setup also establishes the verified webhook path used for CRM activity. Choose the people,
companies, deals, notes, or other supported object/event scope in the destination Brain. Connecting
the key without a Brain source selection does not start ingestion.
