## What connecting does

iMessage is a feature-gated personal connection. When the related preference is enabled, the user
pairs their own phone number with a one-time code so opencompany can send important updates.

## Scopes and permissions

The pairing authorizes the verified phone destination; it does not create a general iMessage inbox
credential. Delivery types, limits, and troubleshooting guidance are coming soon.

## Brain ingestion

iMessage is not a Brain source.
