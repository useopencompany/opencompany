## What connecting does

The Claude Code connection authorizes the Claude Code engine used by cloud coding Chats. It is a
personal engine connection rather than a workspace-shared Anthropic API key.

## Scopes and permissions

Claude Code uses its own subscription authentication flow. Detailed login, expiration, and
reauthorization troubleshooting is coming soon. Repository and secret access remains governed by
the separate connections available to the coding workspace.

## Brain ingestion

Claude Code is not a Brain source and its Conversation is not ingested automatically.
