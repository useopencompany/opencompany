The HubSpot Plugin provides live tools through HubSpot's hosted MCP server. Its account connection
is separate from any legacy ingestion connection.

## Connect HubSpot

1. Ask a workspace admin to install **Settings → Plugins → HubSpot**.
2. Connect the HubSpot account you want opencompany to use.
3. Complete the provider authorization and return to the Plugin page.
4. Review the connected identity and tool permissions.

An administrator of the HubSpot account must authorize the MCP auth app before other users in that
account can connect it.

## Try it

```text
Find the company record for Acme in HubSpot.
Summarize its current CRM information and link the records you used.
Identify missing information for me to review.
```

Replace the company name with a record your account can access.

## Permissions

| Group | What it allows | Default |
| --- | --- | --- |
| **Inspect HubSpot structure** | Access information, schemas, properties, and tool guidance | On |
| **Read CRM & marketing data** | Records, conversations, owners, campaigns, and analytics | Ask |
| **Change HubSpot** | Supported record and marketing-content changes | Ask |

New or unclassified tools require confirmation. HubSpot also enforces the connected user's own
permissions. If HubSpot Sensitive Data is enabled, its MCP server blocks activity objects and
conversation data. If the provider adds required scopes, reconnect the account to grant them.

## Knowledge ingestion

HubSpot isn't offered by the current **Wiki → Sources** picker. Legacy ingestion configurations,
where available, have separate credentials and scope; Plugin installation doesn't enable them.

To reuse a finding, ask the agent to save a reviewed summary with HubSpot source links in Wiki.
