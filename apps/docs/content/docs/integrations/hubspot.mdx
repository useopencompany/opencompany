## What connecting does

HubSpot connects a CRM account so OpenCompany can work with the authorized portal and identify the
account behind later provider activity.

## Scopes and permissions

The full OAuth scope and supported action matrix is coming soon. Review the HubSpot consent screen
and the account identity shown in OpenCompany before using the connection across a workspace.

## Brain ingestion

HubSpot can ingest selected activity for contacts, companies, and deals. Choose the allowed objects
and event types in the destination Brain's Sources settings; connection alone does not enable them.
