## What connecting does

GitHub is a workspace connection managed by workspace admins. It gives opencompany an authorized
GitHub App relationship for the repositories selected during setup and supports repository-aware
coding work.

## Scopes and permissions

Repository installation scope is the outer boundary. A complete mapping of GitHub App permissions to
opencompany actions is coming soon; review the selected repositories and GitHub's installation
permission screen when connecting or changing access.

## Brain ingestion

GitHub can feed new issues plus new or merged pull-request activity from repositories selected in a
Brain's Sources settings. Connecting the App alone does not select repositories for that Brain.
