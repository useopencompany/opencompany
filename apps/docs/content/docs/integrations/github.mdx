## What connecting does

GitHub is a personal connection provided by the official **GitHub as you** Plugin. It lets
opencompany work with repositories, issues, and pull requests using the GitHub identity you
authorize, including repository-aware coding work.

## Scopes and permissions

Repository installation scope is the outer boundary. Review the selected repositories and GitHub's
installation permission screen when connecting or changing access.

## Connect GitHub

Open **Plugins**, choose **GitHub as you**, install the plugin, and authorize the GitHub App. GitHub
workspace ingestion is no longer available; use the plugin whenever opencompany needs GitHub access.
