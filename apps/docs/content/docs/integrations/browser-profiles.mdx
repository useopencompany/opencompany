---
title: Browser profiles
description: Save a site login for authenticated browser work.
---

Browser profiles let you save a personal login session for a specific site. This feature is
available only when enabled for your account.

## Connect a profile

1. Open **Settings → Account** and find **Browser profiles**.
2. Enter a profile name and the site's URL.
3. Select **Connect**.
4. Complete the site's login in the **Login handoff** view. Use **Open** if you need a separate tab.
5. Select **I'm logged in** to save the session.

Check the site's account identity during login. The browser session carries that account's access
to the site.

## Use it

Ask the agent to use the named profile for a bounded browser task:

```text
Use my saved Support portal browser profile to read the release ticket.
Summarize its current status and unresolved questions.
```

Authenticated browser work can show a live view in Chat so you can see the active session.

## Reconnect or remove

If a profile loses its login, open the profile in Account settings and use **Reconnect** when shown.
Complete the login handoff again. Use the delete control to remove a saved profile you no longer
need.

A profile doesn't continuously ingest site content into Wiki. Ask the agent to save a result
explicitly when it should become shared knowledge.
