Connect Codex to use your ChatGPT subscription for Codex coding sandboxes in opencompany. This is
a personal engine connection; each teammate connects their own account.

## Connect

1. Open **Settings → Inference → Coding subscriptions**.
2. Select **Connect** on the Codex card.
3. Open the displayed Codex sign-in link and enter the displayed code.
4. Complete sign-in, return to opencompany, and wait for the connection to validate.
5. Start a new Chat and choose Codex and an available model.

If the sign-in code expires, start the connection flow again. If an existing credential needs
reauthorization, use the connection control on the same card and check its status after returning.

## Give it a repository

Engine authentication and repository access are separate. Connect
[GitHub](/docs/integrations/github), then tell Codex which repository to work on. Use
**Settings → Repositories** for shared environment files and setup instructions.

See [Cloud coding](/docs/guides/cloud-coding) for a first change, verification, and PR handoff.

## Continue and customize

Later messages in the same Chat continue the persistent cloud session when available. The composer
shows Codex-specific model, reasoning, plan, and goal controls where applicable. Workspace Skills
and supported Plugin tools can be available to the session; Plugin tools must be set to **On**.

Codex can use workspace Wiki tools. Its transcript isn't automatically saved as Wiki knowledge;
ask it to save the useful result explicitly.

For the separate option to share supported model access through an admin's subscription, see
[Models and usage](/docs/core-concepts/models-and-usage).
