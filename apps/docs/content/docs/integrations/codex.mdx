## What connecting does

The Codex connection authorizes the Codex engine used by cloud coding Chats. A successful connection
is validated and stored for the signed-in person; it is not shared as a workspace API key.

## Scopes and permissions

Codex uses its own subscription authentication flow. Detailed login, expiration, and reauthorization
troubleshooting is coming soon. Repository and secret access still comes from the separate tools and
connections available to the coding workspace.

## Brain ingestion

Codex is not a Brain source. A Codex Conversation can receive scoped Brain read and capture tools
when a Brain is pinned, but its transcript is not ingested automatically.
