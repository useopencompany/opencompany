## What connecting does

Google Calendar is a personal OAuth connection for reading calendar context and creating or updating
events through permitted agent actions.

## Scopes and permissions

Calendar reads and writes follow separate action modes where exposed in Settings. A complete Google
OAuth scope and supported-field reference is coming soon. Confirm event writes when the action is set
to **Ask**.

## Brain ingestion

Google Calendar is not a selectable Brain source in the current UI. Connecting it does not create a
calendar ingestion feed.
