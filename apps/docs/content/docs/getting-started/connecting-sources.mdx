---
title: Connect your tools
description: Install a Plugin, connect your account, and verify the agent can use it.
---

Plugins give opencompany access to external tools. Install the provider's Plugin in your workspace,
connect your account, and choose which actions the agent can perform.

## Install and connect

1. Open **Plugins** in the sidebar, or **Settings → Plugins**.
2. Search for a provider. The **Installed** filter shows Plugins already in your workspace.
3. If the Plugin isn't installed, a workspace admin can select **Install**.
4. Open its page and complete the connection flow. Depending on the provider, you'll authorize
   an account in the browser or enter an API key in the settings form.
5. Check the connected account's identity and status. Installing a Plugin alone doesn't authorize
   an account.
6. Review its tool permission groups, then start a Chat with a small request.

For GitHub, a useful first check is:

```text
Using GitHub, list the open pull requests in OWNER/REPO.
Include the author, title, and link for each one.
```

Replace `OWNER/REPO` with a repository the connected account can access. If access is missing,
follow the [GitHub setup guide](/docs/integrations/github).

## Choose permissions for the work

| Mode | Effect |
| --- | --- |
| **On** | The agent may use the action without a separate approval for each call. |
| **Ask** | Interactive Chat requests approval before the action runs. |
| **Off** | The action is unavailable to the agent. |

Coding sessions receive Plugin tools set to **On**. Background work cannot depend on you responding
to a live approval. Check [Permissions](/docs/core-concepts/integrations) before moving a successful
interactive task into automation.

The provider account still determines which resources you can access. Turning a permission **On**
doesn't grant access to a repository, document, or workspace that the account cannot use.

## Connect knowledge sources separately

Use **Wiki → Sources** when you want selected provider activity to become shared Wiki knowledge.
This is a separate setup from making live tools available in Chat.

The current source picker offers **Gmail**, **Linear**, and **Granola**. Gmail and Linear require
scope selection; Granola uses a separate API-key connection for ingestion. Installing a Plugin for
another service doesn't add it to this picker. See [Wiki sources](/docs/core-concepts/wiki#connect-sources).

## Other connection settings

- Connect personal Codex or Claude Code subscriptions under **Settings → Inference → Coding
  subscriptions**. See [Cloud coding](/docs/guides/cloud-coding).
- Configure repository environments and setup instructions under **Settings → Repositories**.
- When enabled for your account, manage [Browser profiles](/docs/integrations/browser-profiles)
  under **Settings → Account**.

Browse the [provider guides](/docs/integrations) for account setup, examples, and limitations.
