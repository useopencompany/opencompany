---
title: Workspaces
description: Know where work is shared and which settings belong to you or your team.
---

A workspace groups your team's Wiki, installed Skills and Plugins, Workflows, and shared settings.
Choose the workspace where the work belongs before starting a job or saving company knowledge.

## Switch workspaces

Use the workspace switcher in the sidebar. Connections and knowledge available to the agent depend
on the active workspace and signed-in account. Switching workspaces doesn't merge their content.

## Admins and members

| Action | Who can do it |
| --- | --- |
| Work in Chat and read or edit Wiki pages | Workspace members |
| Use Tasks, Workflows, and schedules | Members who have enabled **Tasks & Workflows** in Preferences |
| Create or edit workspace Skills and install or manage Plugins | Workspace admins |
| Manage shared repository setup, model access, billing, and membership | Workspace admins |
| Connect a personal provider account or coding subscription | The person using that account |

Tasks & Workflows is a personal beta preference. If a teammate doesn't see it, they can enable it
under **Settings → Preferences → Beta features**.

## Installed Plugin versus connected account

A Plugin is installed once for the workspace. Many providers then ask each teammate to connect a
personal account. For example, the GitHub Plugin acts through the GitHub identity you authorize;
installing it doesn't give every member access to your private repositories.

Some connections are workspace-managed. Infisical and shared model access have admin controls.
Follow the provider's setup page and check the displayed account identity.

Use [Connect your tools](/docs/getting-started/connecting-sources) to set up the accounts a job needs.

## Shared knowledge

Wiki pages are shared with workspace members. A personal source can contribute to that shared
knowledge, so choose its scope with the destination workspace in mind.

Legacy Brain, where enabled, has its own visibility settings for individual Brains. Those settings
don't restrict Wiki pages. See [Wiki](/docs/core-concepts/wiki) and [Brain](/docs/core-concepts/brain).

## Invite teammates

Open **Settings → Members** as an admin to manage membership and invitations. If your plan's member
limit prevents an invitation, review the upgrade option in Billing.
