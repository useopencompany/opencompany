---
title: Quickstart
description: Get from your first prompt to a useful result, then save or repeat the work.
---

This guide walks you through a first session: ask for a concrete deliverable, review it, and decide
what to keep. You'll need an opencompany account and a workspace. No repository or connected app is
required for the example below.

## 1. Open your workspace

Sign in at [opencompany.chat](https://opencompany.chat). Check the workspace name in the sidebar;
this determines which Wiki, Plugins, and shared settings you're using. If you're joining a team,
use its workspace before connecting accounts or saving company knowledge.

## 2. Ask for one useful result

Start a new Chat. Use the built-in opencompany engine for this first task. Paste your notes or
attach a file, then describe the result you want:

```text
Turn these release notes into an internal launch brief.
Include what changed, who it affects, and what we still need to verify.
Use only the notes I provide. Mark missing information as an open question.

[Paste your notes here]
```

You should get a brief you can review in the conversation. If the agent creates a document, open
its card to read it in the side panel. You can resize the panel or open it full-screen.

## 3. Review and refine

Check the facts and open questions, then give feedback in the same Chat:

```text
Make the brief useful to an engineer taking over the release.
Put the remaining verification steps in order and preserve the open questions.
```

Follow-ups retain the conversation's context. Expand tool activity when you need to inspect what
the agent read or changed. If you leave or reload the page, reopen the same Chat to check progress.

## 4. Add a tool when you need one

For live company context, open **Plugins** in the sidebar, find a provider, and install it if you're
a workspace admin. Each person connects the account they want the agent to use. Review the
available actions and their **On**, **Ask**, or **Off** permissions.

For example, after connecting Linear:

```text
Read the open issues for our release in Linear and compare them with this brief.
Link each issue you cite. Suggest changes to the brief for me to review.
```

In interactive Chat, actions set to **Ask** show an approval request before execution. See
[Connect your tools](/docs/getting-started/connecting-sources) for the full setup.

## 5. Keep what you'll reuse

Choose the next step based on what you want to preserve:

- **The knowledge:** ask the agent to save the reviewed brief in [Wiki](/docs/core-concepts/wiki),
  then open the page to verify it.
- **The method:** if you're a workspace admin, ask “Turn this process into a Skill.” Review its
  reusable instructions under [Settings → Skills](/docs/core-concepts/skills-and-plugins).
- **The job:** start a [Task](/docs/core-concepts/tasks) for work you want to track separately.
- **The recurring process:** create a [Workflow](/docs/core-concepts/workflows-and-schedules).

Tasks and Workflows are a beta feature. Enable **Tasks & Workflows** under
**Settings → Preferences → Beta features** before using them.

For repository work, continue with [Cloud coding](/docs/guides/cloud-coding).
