If you're returning after the recent product updates, use this map to find the current setup path.

| Previously | Now | Next step |
| --- | --- | --- |
| Integrations settings | **Plugins** in the sidebar or **Settings → Plugins** | Install the provider's Plugin and connect your account on its page. |
| Brain as the default knowledge surface | **Wiki** | Create shared pages or configure **Wiki → Sources**. Brain remains available in workspaces with legacy Brain enabled. |
| Codex and Claude Code in Integrations | **Settings → Inference → Coding subscriptions** | Manage your personal engine connection there. |
| Browser profiles in Integrations | **Settings → Account** | Look for Browser profiles when the feature is enabled for your account. |
| Built-in workspace GitHub connection | **GitHub as you** Plugin | Connect your personal GitHub identity and grant access to the required repositories. |
| Brain-backed Skill editing | **Settings → Skills** | Create or import a standard Skill, or ask Chat to turn a successful process into one. |

## Reconnect providers through Plugins

If an old built-in connection stopped working, open the provider's Plugin page and complete the
current connection flow. Check the account identity and permission groups after returning.

Plugin access and knowledge ingestion have separate settings. The current Wiki source picker offers
Gmail, Linear, and Granola; older documentation or an existing legacy connection doesn't imply that
every Plugin is available as a Wiki source.

## Enable Tasks and Workflows

If the task board, Workflow picker, or scheduling controls are missing, enable
**Tasks & Workflows** under **Settings → Preferences → Beta features**.

Use `#task` for a tracked background job, `#` to select a Workflow, and `/` to select a Skill.
A leading `&` starts a separate Chat in the background.
