Wiki is opencompany's default knowledge surface. Brain remains available in workspaces with the
legacy Brain setting enabled. If opening Brain takes you to Wiki, use the
[Wiki guide](/docs/core-concepts/wiki).

## What Brain stores

Brain contains compiled Markdown knowledge pages, evidence snapshots, uploaded files, provenance,
and links between related subjects. Pages hold the current understanding; evidence preserves source
material. Links point back to provider systems when those systems remain the canonical source.

Brain is separate from both Chat history and Wiki. A conversation doesn't automatically become a
Brain page, and Wiki pages don't inherit a Brain's visibility settings.

## Read and capture knowledge

Where Brain is enabled and available to a conversation, the built-in agent can search and read it.
An explicit request to save knowledge captures a draft for background curation. Coding sessions and
authenticated MCP clients can receive scoped Brain tools when configured.

Check the destination Brain and resulting page after saving. Captured drafts may need curation
before they become active knowledge.

## Sources and visibility

Legacy Brain sources are configured for a specific Brain. The providers and scopes available there
can differ from the current Wiki source picker. Pausing ingestion stops later work without silently
deleting pages already curated.

A Brain can be workspace-visible or restricted to selected members. Access checks apply to pages,
source configuration, tools, and file downloads. Uploaded files require authenticated access.

For new shared knowledge, start with [Wiki](/docs/core-concepts/wiki). To make provider tools
available for live work, use [Plugins](/docs/core-concepts/plugins).
