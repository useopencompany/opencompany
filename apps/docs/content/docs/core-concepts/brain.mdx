---
title: Brain
description: Keep reusable workspace knowledge with provenance, controlled sources, and durable files.
---

Brain is OpenCompany's durable knowledge store. It contains Markdown knowledge pages, immutable
evidence, uploaded files, provenance, and links between related subjects. It is not a copy of every
Conversation and it is not a mirror of every connected provider.

## Pages, evidence, and sources

Knowledge pages hold the current compiled understanding of a person, company, project, meeting,
concept, source, analysis, or note. Evidence records preserve source material that has no dependable
live home. Source links point back to systems such as GitHub, Linear, Gmail, or Google Drive when the
provider should remain canonical.

Curated active pages require provenance. Draft captures can land in `inbox/` immediately and be
filed, merged, or promoted by the background curation path later.

## Reading and saving from Chat

The OpenCompany engine can search and read the Brains available to the Conversation. When you
explicitly ask it to remember or save something, `save_to_brain` captures a draft and queues durable
curation. The model does not receive unrestricted document mutation access.

Codex can receive Brain tools when a Brain is pinned to its coding Conversation. External MCP
clients can use the authenticated Brain read surface and, for workspace admins, the same
capture-to-curation path.

## Ingestion

Provider ingestion is durable and scoped to one Brain. A configured source creates normalized source
items and jobs; background workers validate, claim, and settle those jobs. Pausing a source stops
later ingestion but does not silently delete knowledge that was already curated.

Uploaded files are private. OpenCompany stores the bytes behind authenticated access and extracts
supported text for search and curation.

## Visibility

A workspace-visible Brain is available to current workspace members. A restricted Brain requires an
explicit membership. That rule is checked for UI reads, API commands, MCP, ingestion, and file
downloads rather than being trusted from the browser.
