Use Chat for interactive research, writing, analysis, and coding. You can attach files, use
connected tools, apply Skills, and refine the result through follow-up messages.

## Choose an engine

The engine determines where and how the work runs. The model is the AI used by that engine.

| Engine | Use it for | Setup |
| --- | --- | --- |
| **opencompany** | Research, documents, connected actions, and Wiki work | Use an available model in the composer. |
| **Codex** | Repository work, terminal commands, and files in a persistent cloud sandbox | Connect a personal subscription in **Settings → Inference**. |
| **Claude Code** | Coding and file work in a persistent cloud sandbox using Claude Code | Connect it separately in **Settings → Inference**. |

Use the model picker to see what's available. Automatic model routing is a beta preference under
**Settings → Preferences**; when enabled, it chooses a model from the first message and keeps that
choice for the Chat. For subscription setup and shared model access, see
[Models and usage](/docs/core-concepts/models-and-usage).

## Give the agent useful context

Include the outcome, relevant inputs, scope, and how you'll judge the result. Paste short context,
attach a file, or ask the agent to read a specific connected resource or Wiki page.

```text
Read the release checklist in our Wiki and the attached test results.
Produce a go/no-go recommendation with evidence for each checklist item.
List missing evidence separately so I can resolve it.
```

Type `/` to select an installed [Skill](/docs/core-concepts/skills-and-plugins). Give exact repository
names, issue IDs, page paths, and date ranges when you have them.

## Review the work

The transcript shows replies and tool activity. Expand a tool call to inspect its inputs and
results. Answer questions or approve an action in the conversation when prompted. Plugin actions
set to **Ask** wait for your approval in interactive Chat.

Documents can appear as cards. Open a card to read the document in a resizable side panel or
full-screen. Finished files appear as downloadable artifacts when the agent publishes them.

When a result needs revision, reply in the same Chat. To reuse a fact in future work, explicitly ask
the agent to save it in [Wiki](/docs/core-concepts/wiki) and verify the resulting page.

## Leave, resume, or stop

Unsent text and selected mentions on Home and in each Chat survive a refresh in the same tab.
Drafts stay separate by Chat, workspace, and account, and edits are not synced between tabs.
Sending or deleting the text clears its draft. Attachments are not restored after a refresh.

Accepted work is saved independently of the browser stream. You can navigate away and return to
the same Chat to inspect progress. Reloading doesn't mean you need to send the prompt again.

Canceling stops the active run and preserves earlier messages. Long conversations may compact
older context to keep working; use Wiki or a Skill for information you want to reuse reliably
across conversations.

To launch a separate Chat without leaving your current view, prefix a prompt with `&`. For a job
with a tracked status and outcome, use [Tasks](/docs/core-concepts/tasks) instead.
