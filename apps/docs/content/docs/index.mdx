opencompany is an AI workspace for getting work done across your company. Ask questions, work with
connected tools, edit code in a cloud sandbox, and delegate tasks that continue while you're away.
Save what your team learns in Wiki and turn repeatable work into Skills and Workflows.

## Start here

Follow the [Quickstart](/docs/getting-started) to produce your first useful result. You can start with
a prompt and a file; connect an account when the work needs it.

## What do you want to do?

| Goal | Guide |
| --- | --- |
| Ask questions, analyze files, or write a document | [Chat and engines](/docs/core-concepts/chat-and-engines) |
| Work with GitHub, Linear, Gmail, or other tools | [Connect your tools](/docs/getting-started/connecting-sources) |
| Fix a bug or build a feature | [Cloud coding](/docs/guides/cloud-coding) |
| Hand off work and return to the result | [Tasks](/docs/core-concepts/tasks) |
| Run the same process again or on a schedule | [Workflows and schedules](/docs/core-concepts/workflows-and-schedules) |
| Give the agent a reusable way of working | [Skills](/docs/core-concepts/skills-and-plugins) |
| Build shared company knowledge | [Wiki](/docs/core-concepts/wiki) |

## Understand your workspace

Start with [How opencompany fits together](/docs/core-concepts) for the relationship between Chat,
Tasks, Workflows, Skills, Plugins, and Wiki. See [Workspaces](/docs/getting-started/workspaces) for
shared settings and personal accounts, and [Permissions](/docs/core-concepts/integrations) for what
an agent can do through a connection.

Returning after an update? See [What's moved](/docs/getting-started/whats-moved). For a missing tool,
waiting task, or connection problem, use [Troubleshooting](/docs/guides/troubleshooting).

The [API reference](/docs/api-reference) documents the product's HTTP contract. Contributor setup
lives in the [repository](https://github.com/useopencompany/opencompany).
