opencompany is an AI workspace for conversations, durable Tasks and Workflows, connected
integrations, Brain knowledge, and cloud coding sessions. Work happens inside a workspace so the
people, connections, knowledge, and automation involved stay in the same access boundary.

## Start here

- [Getting started](/docs/getting-started) explains the product, workspaces, and how to connect a
  source without accidentally ingesting more than you intended.
- [Core concepts](/docs/core-concepts) explains Chat engines, Tasks, Workflows and schedules, Brain,
  and integrations.
- [Integrations](/docs/integrations) lists the providers represented in the current product UI.
- [API reference](/docs/api-reference) renders the current opencompany OpenAPI contract.

These docs describe the product as it works today. Contributor setup and architecture decisions
remain in the main repository documentation.
