## What the connection does

Revolut Business is an experimental, env-gated, read-only tool connector for main chat. It is meant to let us test the Business API shape before building the full admin connection flow.

Once configured for one workspace, opencompany can answer bounded questions about:

- Revolut Business accounts visible to the access token.
- Expenses for a date range.
- Expenses in `missing_info`.
- Expenses whose `receipt_ids` are empty or absent.
- One expense by id.

This connector does not upload receipts, create bills, create payment drafts, initiate payments, cancel payments, exchange currency, read card-sensitive data, register webhooks, or save Revolut data to Brain automatically.

## Configure the test connector

Set these server-side env vars in the app and runner environment where chat actions resolve:

| Var | Required | Purpose |
|---|---:|---|
| `REVOLUT_BUSINESS_WORKSPACE_ID` | Yes | The only workspace that should see the Revolut action source. opencompany hides the source for every other workspace. |
| `REVOLUT_BUSINESS_API_TOKEN` | Yes | A short-lived Revolut Business API access token with `READ` scope. It should start with `oa_prod_` or `oa_sand_`. Do not use a refresh token, client assertion JWT, private key, or `PAY`-scoped token here. |
| `REVOLUT_BUSINESS_ACCOUNT_LABEL` | No | Friendly label shown in the action source, for example `Acme Revolut`. |
| `REVOLUT_BUSINESS_API_BASE_URL` | No | HTTPS Business API base URL. Defaults to `https://b2b.revolut.com/api/1.0` for `oa_prod_` tokens and `https://sandbox-b2b.revolut.com/api/1.0` for `oa_sand_` tokens. |

The access token expires after about 40 minutes. For this first test connector, generate a fresh access token manually and update `REVOLUT_BUSINESS_API_TOKEN` when Revolut rejects it. The full OAuth/certificate and refresh-token flow should be a follow-up after the API shape feels right.

## Use it in chat

Examples:

- "List my Revolut Business accounts."
- "Show Revolut expenses in July with missing info."
- "Find Revolut expenses from July that have no receipt IDs."
- "Get Revolut expense `expense_id_here`."

Main chat first discovers the Revolut action contract, then runs the read-only action. Large expense periods are bounded to one year and one page of up to 100 expenses. If the provider returns the requested limit, narrow the date range for completeness.

## Safety notes

Only use a `READ`-scoped Business API token. Do not configure `PAY`, `WRITE`, or `READ_SENSITIVE_CARD_DATA` for this test connector.

The env token is server-side only and is never returned to the browser or model. Action results omit account numbers, full card details, and receipt binary content.
