## High-level flow

```text
Browser
  GoatSurface
    typed /v1 Message, Conversation, Run, approval, attachment, and runtime commands
    semantic Run event stream
    authorized API-owned Electric read models

API
  authenticate Actor and workspace on every /v1 route
  validate and atomically persist commands
  serve durable state, semantic events, and fixed read models

Runner
  claim queued Runs with fenced leases and per-session FIFO
  execute OpenCompany, Codex, or Claude Code
  settle Messages, Events, artifacts, usage, approvals, and terminal state
```

## Chat

`apps/web/components/GoatSurface.tsx` uses the typed protocol client through
`headless-chat-transport.ts` and `headless-chat-commands.ts`. Sending a Message creates a stable Run
under an idempotency key. Engine choice and settings are versioned descriptors on that same command.
Closing the browser does not end execution; the runner continues from Postgres and the UI reconnects
through durable read models and semantic Events.

Shared tools and provider-neutral behavior live in `packages/goat-agent`. Public command handling is
composed in `apps/api`; durable engine execution is composed in `apps/runner`.

## Tasks

Manual, Workflow, schedule, and agent producers enter `TaskApplicationService`. Creation writes a
Task, Conversation, initial Message, and Run atomically. Follow-ups use the Message command and stop
targets the active Run.

The 35 sessionless historical Tasks remain available only through an actor-scoped, read-only
compatibility API. They are a separate ADR 0002 retention gate.

## Boundaries

- Protocol DTOs contain no credentials, secret values, private storage locators, WorkOS IDs, or
  physical database types.
- Every `/v1` route authenticates an Actor and enforces workspace membership.
- The runner owns durable execution, coding sandboxes, and fenced lease settlement.
- The web app owns presentation and uses typed API clients for Chat and Task data.
- Schema changes belong in `packages/db` and require additive Drizzle migrations.
