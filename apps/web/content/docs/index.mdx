## What these docs are

These embedded docs are an engineering reference for the current product: how the browser, API,
runner, Brain, and integrations fit together.

They are intentionally close to the app code. The source lives in `apps/web/content/docs`, and the rendered docs live at `/docs` inside the web app.

## Current product shape

OpenCompany's main work surfaces are:

- **Chat** for direct answers, quick tool use, and starting durable background work.
- **Tasks** for durable work that keeps running through the runner service.
- **Workflows and schedules** for reusable or recurring Task creation.
- **Brain and integrations** for durable knowledge and connected company context.

Treat these pages as implementation notes, not a public user manual.
